速查：六组件 / 八动词 / claim levels / 禁词

把全书最常要"一眼确认"的硬清单压成几张紧凑表格：拆后端的六组件、RPF 八动词、由窄到宽的 claim levels、core 禁词、metric families、no-silent-fallback 的 blocked 状态、五条能力轴。日常写 PR、填 profile、划 claim boundary 时直接抄。

六个 backend 组件

组件定义例子
platform集成环境 / 仿真器外壳Isaac Sim; MuJoCo; Genesis; split backend; real robot runtime
physics物理转移动力学来源PhysX; Newton; MuJoCo physics; Genesis physics; real world; reduced semantic physics
renderer图像类观测来源Isaac RTX; Blender Cycles; MuJoCo renderer; real camera; offline rerenderer
sensors传感器读出来源RGB; depth; segmentation; force/torque; tactile; proprioception; instrument logs
control动作执行接口joint action; ee-delta; action chunk; skill command; ROS control; articulation controller
process runtime场景专属语义状态转移来源reduced liquid model; device state machine; hazard event generator; conveyor; terrain transition

跨后端实验只改一个组件：说"Compare PhysX vs MuJoCo physics while keeping task & metric spec fixed"，不说"Compare Isaac vs MuJoCo"。

RPF 八动词

runtime/provider_facade.py
materialize → reset → apply_state → apply_control → step → measure   ← 前七个驱动一次 run
                                                              query   ← 取证据（telemetry/diagnostics/native dump）
                                                              close   ← 收尾

证据边界 = provider 产出的 artifact-backed L3 measurement。单个 simulator 字符串不是 EOS 里的 backend identity。注意：这八个是 EOS 的 RPF 动词，不是 MetaSim 的（MetaSim 没有"恰好八个动词"的列表）。

release claim levels（由窄到宽，不许跳级）

docs/design/release-claim-boundary.md
contract implemented
  → fixture conformance passed
    → live SDK lane executed
      → scenario evaluator executed
        → suite diagnostic executed
          → release live gate passed

"a live SDK lane is not a benchmark score, and a scenario evaluator result is not backend parity."

metric families（core 定义，pack 实例化）

family测什么
task_outcome任务成败
procedure流程步骤有效性
state_transition状态转移正确性

hazard危险检测/安全（DDR、FNR-H…）
prediction世界模型预测（STE、DCS…）

family 是抽象的——不许出现 pipetting/contamination/conveyor 这类领域词。

no-silent-fallback：blocked_* 状态

缺证据要变成显式状态，绝不变成 0.0 / [] / {} / success=true / score=1.0 / default pass：

显式 blocked / 不可用状态
blocked_missing_measurement   blocked_missing_state
blocked_missing_artifact      blocked_invalid_action
blocked_control_rejected      blocked_provider_unavailable
blocked_optional_dependency   unsupported   not_evaluated

报告必带分母与逐轴状态：runtime_execution_rate / model_action_valid_rate / control_acceptance_rate / projection_ready_rate / evaluator_pass_rate / render_capture_rate / artifact_linkage_failures / blocked_* counts。
