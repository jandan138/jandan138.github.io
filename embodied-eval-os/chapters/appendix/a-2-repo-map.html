仓库与文件地图

读架构最快的方式是知道每样东西住在哪。这一页给一张带注释的目录树，对应仓库根 /cpfs/user/zhuzihou/dev/embodied-eval-os。记住那条贯穿全书的依赖方向：core ← scenario_packs / adapters / backends / model_adapters，core 永远不反向 import 它们。沿着这棵树看，依赖方向几乎一目了然。

为什么 runtime/ 不在 core/

注意 src/embodied_eval_os/runtime/ 和 src/embodied_eval_os/core/runtime/ 是两个不同的地方。L2 的 WorldSession、RPF facade、live model loop 住在顶层 runtime/——它们是 live 运行时机器，会牵扯具体后端。core 里的 core/runtime/ 只放契约级的东西（EpisodeRunner 路径 A、强类型验收 episode_execution.py、证据链/状态迁移契约）。这条分界正是"core 保持 domain-agnostic、live 复杂度往外推"的物理体现。
