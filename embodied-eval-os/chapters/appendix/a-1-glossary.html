术语表 Glossary

这本书塞了很多英文术语——这是故意的：架构名、类名、状态名、claim 词汇都该保留原文，方便你回头对照代码和设计文档。这一页把它们集中起来，每个一行中文释义。按主题分组，随手查。术语首次出现处可顺着正文链接回去看上下文。

项目定位

术语一行释义
EOS / EmbodiedEval OSa domain-agnostic, backend-composable evaluation OS for embodied intelligence——比 benchmark 高一层的具身评测操作系统。
scenario pack装某个领域语义（任务/资产/过程原语/度量/协议）的可插拔包；不改 core 抽象。home_manipulation、scientific_lab 等都是 pack。
adapter / anti-corruption layer把被导入的外部 benchmark（EBench、AutoBio…）接进来的防腐层；不得反向塑造 core API。
claim boundaryEOS 签名概念：每个结果都要写明"证明了什么 / 不能证明什么"。semantic proxy ≠ real CFD，compatibility smoke ≠ full reproduction。
no-silent-fallback缺证据要变成显式 blocked_* 状态，绝不许默默填 0 / [] / success=true。

L0–L6 分层与状态

术语一行释义
L0–L6分层栈：L0 Resource/Asset → L1 EvaluationWorldSpec → L2 WorldSession → L3 RuntimeMeasurementSnapshot → L4 PhysicalStateProjection → L5 TaskSemanticState → L6 Evidence Ledger / EpisodeTrace。
WorldSession (L2)live runtime 的 session 信封（lifecycle/clock/channels/control/sensors/artifact refs）；在 runtime/，不在 core；不是 USD clone，不拥有 per-step state。
RuntimeMeasurementSnapshot (L3)measured/exported 的跨后端证据边界；immutable、artifact-backed、capability-scoped；不保证完整/可恢复/可独立比较。
PhysicalStateProjection (L4)backend-normalized、simulator-neutral 的物理投影；字段含 time_s/robots/objects/joints/contacts。State V2 名（原 CanonicalPhysicalState）。
TaskSemanticState (L5)场景拥有的语义/过程状态（process/procedure/hazard 字段）；core 只存 schema-validated payload，不知字段名。原 TaskWorldState。
PredictedFuture世界模型的预测产物：horizon_s + 预测的 semantic/physical state/observation + success_probability + risk_scores。
State V2一次硬改名重构：把 CanonicalPhysicalState→PhysicalStateProjection 等；active API 用 V2，V1 只经迁移模块读，legacy key 会被 from_dict 拒绝。

Trace 与证据

术语一行释义
EpisodeTrace (L6)一次 episode 的证据 artifact：episode/task/pack id、backend_components、versions、privileged_state_policy、claim_boundary、steps、episode_metrics。
TraceSteptrace 的一步：observation/action/physical_state_projection/task_semantic_state/prediction/metric_results + privileged_state_visible_to_model。
TraceStorecore recorder，把 trace 序列化成 JSON（save_json）。
judgeable loop把后端分叉变成完全记账的账本（fairness gates → 物理 verdict）；verdict 词汇 matched/mismatched/blocked_with_evidence/not_compared。
privileged state特权状态（native dump/solver diagnostics/evaluator 真值）；默认不进模型输入，仅 evaluator/recorder 可见。

后端与组合

术语一行释义
BackendProfilefrozen dataclass：profile_id + 六组件（platform/physics/renderer/control/process_runtime/sensors），方法 component_summary()。
ComponentProfile单个组件的描述：name/component_type/version/capabilities/metadata。
六组件platform / physics / renderer / sensors / control / process runtime——后端永远拆成这六格，不许只说"Isaac"。
CapabilityTier组件能力档：NATIVE / REDUCED / SEMANTIC_PROXY / EMULATED / UNSUPPORTED。
capability registry vs readiness ledgerregistry = 静态声明"打算支持什么"；ledger = 这一次实际测到/产出/被 block/失败什么。账本不是分数。
axis-level status账本逐轴状态：exact/approximate/partial/read_only/write_only/opaque_only/unsupported/blocked。
semantic proxy用 reduced 语义模型代替真实物理（如 reduced liquid model）；不声称真物理保真。

Runtime 与 facade

术语一行释义
RPF (Runtime Provider Facade)借 MetaSim 工程外形的 provider facade，但不接受"一 handler 一 backend / handler state 物理可比"的含义。
八动词 (8 verbs)materialize / reset / apply_state / apply_control / step / measure / query / close；前七个驱动一次 run。
EpisodeRunner评测路径 A（简单 in-process）：装 backend+model+spec，run(seed)→EpisodeTrace；强制写六组件。
WR (WorldState Runtime)核心架构 epic（WR-1…WR-8H）；立 L0–L6、把 pickup 任务降级为 regression scenario、引入 paired dynamic trace。
ERF (Embodiment Runtime Foundation)本体运行时地基（ERF-0…6）；显式不是 universal Robot class。
EVL (Visual Model Evaluation Lane)当前前沿：RGB 帧证据 + HTTPPolicyAdapter sidecar + visual_manipulation_micro + 10-episode 诊断 suite。

度量、报告与模型

术语一行释义
MetricResult一条度量结果：name/value/family/unit/details。EpisodeResult 聚合一组 MetricResult。
metric familycore 定义的抽象族：task_outcome/procedure/state_transition/precision/hazard/prediction/planning/resource(+restoration/generalization)。pack 实例化具体 metric。
EvaluatorABC：evaluate_step / evaluate_episode(trace)→EpisodeResult。具体如 TaskOutcomeEvaluator/HazardEvaluator/PredictionEvaluator。
CapabilityProfile多轴报告类型（task/procedure/precision/hazard/prediction/planning/generalization/resource），避免单标量。
ModelAdapter模型契约 ABC：reset/act(必)/predict_future/rank_plans/assess_safety。现有 random/scripted/http policy。
五条能力轴task execution / world prediction (WAM) / safety reasoning / generalization / planning usefulness。

Claim 与硬仗

术语一行释义
release claim levels由窄到宽：contract implemented → fixture conformance → live SDK lane → scenario evaluator → suite diagnostic → release live gate；不许跳级。
Forbidden Claim Catalog未配证据不得用的词：backend/trajectory/force parity、pixel parity、official benchmark reproduction、hardware readiness、real-world safety、MetaSim compatibility…
faithful_reproduction_not_approvedAutoBio 复现清算的判定：roadmap 完成不等于 faithful reproduction 或官方全链执行。
contract closure vs outcome closure关一个"证据链存在" vs 关一个"真实结果成立"——两者必须分清。
AX-1近期活跃架构 cutover/cleanup（见近期 git commit）。
WWSBwetlab_safety pack 对应的 wet-lab safety benchmark（负样本 ≥60%，hazard levels 0–5）。
